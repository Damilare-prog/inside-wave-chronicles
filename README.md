# Inside Wave Chronicles

A cyberpunk-themed Afrobeats & Lifestyle trivia app built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- **Cyborg/Futuristic UI** — Neon glows, glitch effects, scanlines, and grid backgrounds
- **55+ Trivia Questions** — Afrobeats artists, music culture, and Lagos lifestyle
- **Anti-Cheat System** — Session-locked, randomized questions per attempt
- **Timed Challenge** — 45 seconds, 8 questions, 75% pass mark
- **WhatsApp Payment Integration** — Auto-generated token redirects to WhatsApp for ticket payment

## Tech Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## Deployment

### GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings > Pages**
3. Set **Source** to "GitHub Actions"
4. The included workflow will auto-deploy on every push to `main`

### Vercel

1. Push to GitHub
2. Import project on [vercel.com](https://vercel.com)
3. Framework preset: Next.js
4. Deploy
